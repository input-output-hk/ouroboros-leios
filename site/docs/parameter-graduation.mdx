# Parameter graduation

The graduation plan raises the endorser block (EB) parameters step by step, first on the Musashi dojo testnet and then on mainnet. Each step is a point in three dimensions: EB transaction bytes, Plutus steps, and the diffusion period L_diff. The surface shows the minimum L_diff each point needs under the DeltaQ model; a step above it is feasible.

The step marked current is the parameter set active on the network, as shown by [kleioscan](https://kleioscan.com/#/musashi/params). Earlier steps count as accomplished.

:::warning DeltaQ model still being refined

Timing results (needs, P(C), F_full|C) are provisional and not calibrated against testnet data.

:::
