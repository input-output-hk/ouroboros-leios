# Development

This section collects material from the ongoing development of Leios that does not fit elsewhere on this site: not the general introduction in [About Leios](../what-is-leios), and not one of the interactive tools. It is a working area for results and analyses as they come out of development, so expect its contents to change as the work progresses.

Currently, it contains:

- [**Protocol status**](./status) of the Leios components across the stages from CIP to assurance. For a more detailed account, see the [development status report from 2026 Q2](https://github.com/input-output-hk/ouroboros-leios/blob/main/docs/status-report-2026q2.md).
- [**Parameter graduation**](../parameter-graduation), the plans for stepping the Leios protocol parameters up on the network.
- [**Benchmark reports**](./benchmark-reports) of Leios node release candidates, as run by the Performance & Tracing team on the cardano-node benchmarking cluster.
- [**Cost estimator**](./cost-estimator), which projects the operating costs of a Leios node from confirmed transaction throughput.

The [Research and development](./overview) section holds historic material from the research phase of the project. It remains a valid reference wherever it has not been superseded by material in this section.

For the protocol specification, design documents, papers and presentations, see the [Resources](../resources) page.
